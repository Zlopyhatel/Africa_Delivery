# Матрица соответствия бизнес-возможностей и ИТ-сервисов (Services per Capability) — Africa Delivery MVP

Настоящий реестр определяет закрепление ответственности за реализацию ИТ-сервисов, обслуживающих ключевые бизнес-возможности (Capabilities), а также фиксирует внешние технологические зависимости MVP-контура.

| ID | Бизнес-возможность (Capability L2) | ИТ-продукт / Компонент системы | Технический владелец (Owner) | Внешняя зависимость (API / Провайдер) |
| :--- | :--- | :--- | :--- | :--- |
| **01** | 1.1. Мультиканальный интерфейс доступа | Модуль каталога, корзины и витрины приложения (PWA / Go Binary) | Проектная команда (6 инженеров-контракторов) | Нет (Собственная локальная разработка) |
| **02** | 2.1. Мультиканальный онбординг партнеров | Интеграционный модуль регистрации продавцов (WhatsApp-бот адаптер) | Проектная команда (6 инженеров-контракторов) | **Buy:** WhatsApp Business API (Meta), шлюз авторизации |
| **03** | 3.1. Оркестрация и процессинг платежей | Модуль расчетно-платежных операций (`Payment Service`) | Технический директор (СТО Раджеш Менон) | **Buy:** Агрегаторы Paystack API, Flutterwave API, кошелек M-Pesa |
| **04** | 4.1. Управление жизненным циклом заказа | Модуль логики и статусов заказов (`Order Service` / Go) + USSD-текстовый адаптер | Проектная команда (6 инженеров-контракторов) | **Partner:** Телеком-операторы (MTN, Safaricom шлюзы) |
| **05** | 4.2. Операционная доставка и трекинг | Адаптер логистических систем (`Delivery Gateway Adapter` + Transactional Outbox в PostgreSQL) | Технический директор (СТО Раджеш Менон) | **Partner:** API логистических агрегаторов Sendbox (Нигерия), Sendy (Кения) |
| **06** | 5.2. Безопасность, комплаенс и администрирование | Модуль Токенизации ПДн (`Data Residency Router`), контур сбора согласий и ведения Opt-In логов | Технический директор (СТО Раджеш Менон) | **Internal/Buy:** Локальные национальные ЦОД, облачный сервис AWS KMS |
