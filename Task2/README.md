# Часть 2. Базовые архитектурные чертежи, TCO-моделирование и манифест

## Общие сведения
Раздел содержит расчетно-обосновательный базис платформы. На основе сопоставления совокупной стоимости владения (TCO) здесь производится выбор базового архитектурного стиля и формируется сценарий защиты ИТ-стратегии перед Советом директоров в Найроби.

## Состав документов и файлов:
* **`options-comparison.md`** — Числовое сравнение вариантов развертывания (Монолит vs Микросервисы) по критериям стоимости, TTM и рисков.
* **`tco-model.xlsx`** — Пятилетняя финансовая Excel-модель расчета ИТ-себестоимости одного заказа, затрат на инфраструктуру, SaaS и ФОТ разработки.
* **`adr-001-architecture-style.md`** — Архитектурное решение №1. Фиксация выбора Компонентного Модульного монолита на Go + PostgreSQL.
* **`c4-context.puml` / `.png`** — Диаграмма контекста C4, отражающая интеграционные связи ядра маркетплейса со сторонними API (Paystack, M-Pesa, Sendbox, WhatsApp).
* **`use-cases.puml` / `.png`** — Диаграмма прецедентов, разделяющая витрину на визуальный (PWA) и текстовый (USSD/SMS для сельских регионов) контуры.
* **`architecture-vision.md`** — Технический манифест (Architecture Vision) платформы по стандарту TOGAF.
* **`nairobi-script.md`** — Транскрипт выступления архитектора перед инвесторами (1200–1500 слов) на языке ИТ-экономики.
