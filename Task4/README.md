# Часть 4. Топология размещения данных, комплаенс и план отказоустойчивости

## Общие сведения
Раздел регламентирует физическое и логическое распределение данных платформы в рамках законов о суверенитете ПДн (NDPR, KICA, POPIA). Документы описывают гибридную схему токенизации и фиксируют шаги по ликвидации последствий катастрофических аварий.

## Состав документов и файлов:
* **`data-residency-map.md`** — Карта размещения данных по категориям и национальным юрисдикциям субъектов.
* **`cloud-regions-comparison.md`** — Технико-экономический анализ облачных регионов AWS, GCP, Azure и локальных провайдеров.
* **`adr-003-data-residency.md`** — Архитектурное решение №3. Спецификация LUKS-шифрования, управления ключами в AWS KMS и обеспечения обратимости кода.
* **`c4-container.puml` / `.png`** — Диаграмма контейнеров C4 с географическим зонированием компонентов и выделением независимого адаптера логистики.
* **`deployment-diagram.puml` / `.png`** — Физическая схема развертывания серверов, защищенных IPSec VPN-туннелей и сетевых экранов.
* **`failover-plan.md`** — План отказоустойчивости при аварии центрального дата-центра. Описывает шаги, RTO, RPO и роли при переключении.
